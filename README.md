# Genomic signatures of recent human adaptation to the Foraging-to-Farming Transition
Repository of all original code necessary to reproduce results from Chak et al. (link) step-by-step in markdown format. Raw sequencing data generated for this study are only available subject to the data access agreement and deposited on EGA (link), but access to the whole dataset requires requesting data from all other providers. Instead, we provide publicly available summary files, annotation data, and figure source data on Zenodo (link) to facilitate easier replication of main results. For code steps, the script file and main output of the code are specified prior to the code block. Software paths and environments vary across systems so please adapt these for your own system before attempting to replicating analyses. Correspondence to Luis Barreiro (lbarreiro@uchicago.edu).
