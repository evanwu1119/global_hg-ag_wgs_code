# Global Patterns of Recent Human Adaptation to the Foraging-Farming Transition
Repository of all code necessary to reproduce results from Chak et al. (link) step-by-step in markdown format. Processed VCFs and raw sequencing data are only available subject to the data access agreement and deposited on EGA (link), while downstream inputs, summary files, and source data are publicly available on Zenodo (link). Correspondance to Luis Barreiro (lbarreiro@uchicago.edu).
