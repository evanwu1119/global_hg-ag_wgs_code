# Genomic signatures of recent human adaptation to the Foraging-to-Farming Transition
Repository of all original code necessary to reproduce results from Chak et al. step-by-step in markdown format. Raw sequencing data generated for this study are only available subject to the data access agreement and deposited on [EGA](https://ega-archive.org/studies/EGAS50000001991), but access to the whole dataset requires requesting data from all other cohorts and providers. Instead, we provide publicly available summary files, annotation data, and figure source data on [Zenodo](https://doi.org/10.5281/zenodo.21732758) to facilitate easier replication of main results. For code steps, the script file and main output of the code are specified prior to the code block. Software paths and environments vary across systems so please adapt these for your own system (i.e. installing tools and packages) before attempting to replicate analyses.
