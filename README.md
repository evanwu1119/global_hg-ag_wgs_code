# Global Patterns of Recent Human Adaptation to the Foraging-Farming Transition
Repository of all code necessary to reproduce results from Chak et al. (link) step-by-step in markdown format. Processed VCFs and raw sequencing data are only available subject to the data access agreement and deposited on EGA (link), while intermediate inputs, summary files, annotation data from providers, and figure source data are publicly available on Zenodo (link). For code steps, the script file and main output of the code are specified prior to the code block. Software paths and environments vary across systems so please adapt these for your own system before attempting to replicating analyses. Correspondance to Luis Barreiro (lbarreiro@uchicago.edu).
